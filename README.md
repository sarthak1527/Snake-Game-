# 🐍 C++ Raylib Snake Game

A simple retro-style Snake Game built with **C++ and Raylib**.

## ✨ Features

- Classic Snake gameplay
- Arrow-key controls
- Random food generation
- Score tracking
- Wall & self-collision
- Game Over and restart
- Food image and MP3 sound effects
- Modular C++ files

## 🛠️ Tech Stack

- C++
- Raylib
- MSYS2 UCRT64
